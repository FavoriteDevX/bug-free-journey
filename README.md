## 🛠️ How to Add a New Entry
1. Copy the template from `templates/bug-entry-template.md`.
2. Create a new `.md` file inside the corresponding topic folder (e.g., `python/`, `docker/`, `sql/`).
3. Push to the `main` branch. A GitHub Action will automatically update this README index.
